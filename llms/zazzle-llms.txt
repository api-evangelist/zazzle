# Zazzle

> Zazzle is an online marketplace and on-demand manufacturing platform for customized physical
> products — invitations, cards, apparel, mugs, signage and hundreds of other made-to-order goods.
> Zazzle does not publish one general-purpose REST API. It exposes three distinct integration
> surfaces: the Create-a-Product API (a URL "linkover" contract that injects a partner site's images
> and text into a Zazzle product template and returns a purchasable product), the RealView image
> service (renders a product mockup of that template for preview), and the partner-gated Vendor
> (Maker) API (an XML RPC endpoint manufacturing partners use to pull orders, fetch packing sheets,
> and buy or void shipping labels).

Generated by API Evangelist on 2026-08-05. Zazzle publishes no llms.txt of its own
(https://www.zazzle.com/llms.txt returns 404), no OpenAPI, no MCP server, and no A2A agent card.

## What an agent needs to know first

- **No JSON anywhere.** Create-a-Product returns HTML, RealView returns an image, the Vendor API
  returns XML.
- **The Vendor API returns HTTP 200 on error.** Read `Response/Status/Code` from the XML body; a
  client that trusts the HTTP status will treat every failure as a success.
- **No idempotency contract on any surface**, including `getshippinglabel`, which purchases a carrier
  label despite its read-shaped name and HTTP GET verb. Do not retry it blindly.
- **No webhooks or events.** Maker order intake is poll-only via `listneworders`.
- **No sandbox.** Calls go to production. Zazzle does publish a live reference store with working
  example IDs — see the sandbox artifact below.
- **Template parameter names are dynamic**, derived from the URL Parameter Name assigned to each
  object in Zazzle's design tool. There is no fixed parameter list.

## APIs

- [Zazzle Create-a-Product API](https://www.zazzle.com/api): URL linkover API. 1-to-1 via
  `ax=Linkover`, 1-to-many ("Templates Buffet") via `ax=DesignBlast`. Base
  `https://www.zazzle.com/api/create/`.
- [Zazzle RealView Product Image API](https://www.zazzle.com/api): dynamic product mockup rendering.
  Base `https://rlv.zazzle.com/svc/`.
- [Zazzle Vendor (Maker) API](https://makerhelp.zazzle.com/hc/en-us): partner-gated XML RPC for order
  fulfillment. Base `https://vendor.zazzle.com/v100/`. Requires Zazzle-issued credentials.
